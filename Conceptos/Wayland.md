Wayland es el sistema moderno de Linux para:
- dibujar ventanas
- gestionar input
- comunicarse con la GPU

Sustituye a X11.

## Ventajas
- Mejor rendimiento
- Menor latencia
- Mayor seguridad
- Mejor soporte HiDPI

## En Omarchy
- Hyprland funciona SOLO con Wayland
- Todas las apps deben ser Wayland-native o usar XWayland
